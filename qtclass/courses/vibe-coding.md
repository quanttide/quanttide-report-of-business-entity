# Vibe Coding 课程：作品收录、玩法反馈与课堂节奏

来源：量潮课堂 AI 编程社群讨论两日——2026-11-25 冷启动日（67 条）、2026-11-26 复盘日（61 条）。发言人已按职务代称处理。

## 一、学员作品怎么收录：共享文档方案让位于已有网站

有学员提议建一个共享文档，每个人的作品各占一条链接。创始人起初也是这个想法，但课堂网站已经由同事直接做出来了，再开一个文档就会出现「网站和文档同时更新会乱」，打乱现有工作流。

收敛后的方案：把同学作品的链接放进网站「学生作品」区的游戏上方，并显示哪位同学做了哪些东西；做得比较多的做成一个可伸缩的账本。

当场记下的新卡点：部分作品托管在需要科学上网的海外平台上，国内网络和手机端打不开，作者本人之外的人都没法试玩。

## 二、玩法反馈比预想中更值钱

外部顾问试玩后的反馈是「玩法多样性方面还有空间，不知道是不是 vibe coding 的问题」。创始人回：此前一天已经发现，AI 做的模拟经营游戏容易陷入重复。

结合一名学员的学习经验——新手开发者一开始看不到自己的盲区，直到收到反馈才发现——结论是：具体的玩法体感反馈对新手特别有帮助，比泛泛的表扬有用得多。

同时抛出的学员分层初步计划：没有参与、以玩家身份参与、以作者身份产出、以指导者身份帮助，共四个等级。

## 三、游戏设计是比计算器更好的入门项目

顾问的判断：游戏设计涉及产品研发的全流程——故事、美术、开发、测试、宣发，比做计算器、日记本、打卡日历这类项目有价值得多；能把一个复杂游戏做好，做什么 app 都差不多了。

创始人补充：vibe 时代全局意识空前重要，不然一不小心就会被 AI 带跑偏；投入到过分的细节里而迷失，是所有人都会有的问题。

## 四、介绍外部专家的分工套路

创始人定下的做法：本人和我们分别从不同角度介绍，并且必须带上本人的 title、博士身份和研究领域——「这个对学者很重要」。只让一方单方面介绍，容易把人介绍扁。

## 五、创始人对课堂业务的产品思考（可直接复用到游戏机制）

课堂业务和摆摊的不一样：它的不确定性不是摆摊靠天收的客户数量，而是我们自己的节奏。目前定的目标是学员的活跃与交付，决策变量是管理策略。

类比来自餐饮行业调研：普遍痛点是没法预测客人的数量，一多了招待不下、一少了空空荡荡，而且店主普遍说找不到规律。而梳理课堂业务的节奏时会发现，几乎每一个组件环节主动性都比较强、节奏控制得比较准确。

推论：如果把一个靠天收的业务改造成这种结构，就能帮很多企业对自己的业务获得更强的控制感。

映射回主线游戏机制：现在已有的「打听消息」这类玩法，本质上就是在增强控制感的方法，但它还比较初级，完全可以做得更真实——这样游戏的可玩性和对真实经营的启发都会更有效。

## 七、作品页整合进 Lite：两条路线（未裁）

11-25 冷启动日。作品页原型由同事当场做出来（https://quanttide-class-works.app.workbuddy.host/?sharecode=GUCWGLVMLY），创始人的评价是「学以致用，直接拍了个网站展示」。围绕把作品页整合进量潮课堂Lite，当场摆了两条路线：

- **路线 A：放原始链接**——学员作品的原始链接直接进作品区；短板是链接可能随时更新、不稳定。
- **路线 B：复制一份托管**——或者搭一个作品集系统；短板是要大改系统设计。

两条当场未裁。同日先行的是官方作品展示：官方作品是上线在自有网站系统的真实网站，「这个没有分歧」，先上。

作品区的动机设计也在当天定型：把已做成果统一发布到单独标签页，老同学获得试玩反馈、新同学知道怎么下手（可复用形式已上提至 [`../index.md`](../index.md)）。

## 八、署名：脱敏还是真实姓名——当场决定不了

11-25。作品页要显示作者时，问题是脱敏还是真实姓名，创始人的原话是「这个我决定不了了」。收敛到的处理：先与作品同学讨论，看本人是否愿意留真实署名——意愿优先，平台不单方面定。此账未清，作品展示加人名前须先走这一步。

## 九、托管与发行：四条路与一个合规分叉

11-25，卡点当天在群里当场复现：创始人在手机上没有梯子玩不了，一名学员的作品托管在 chatgpt.site（子域含个人账号名，此处不录），作者本人之外没人打得开。出路当场摆了四条：

1. **复制一份代托管**——即路线 B 的托管形态。
2. **学员自己发 TapTap**——个人开发者、不上架广告，门槛可接受。
3. **小红书的小工具**——门槛也低。
4. **公司帮发、上线我们自己的网站**——一旦走公司渠道，就涉及游戏发行的合规问题。

分叉点在第 4 条：公司名义发布触发发行合规，个人渠道门槛低但作品分散。与署名一样，托管方案未最终裁定。
